# Learning Portfolio Decisions

Reproducible code for the direct portfolio learning paper.

- `monte_carlo/`: symmetric Monte Carlo experiments for the theoretical learning rates.
- `empirical/`: real-data Direct Gaussian/Matérn KRR versus same-kernel forecast-then-optimize (full source is also frozen in `bundles/PORTFOLIO_PAPER_EMPIRICAL_SPECTRAL_CODE.zip`).
- `spectral_decay/`: empirical kernel-spectrum decay fits, effective-dimension diagnostics, and histogram analysis (included in the same frozen source bundle).

Licensed WRDS/JKP/CRSP data, credentials, and large proprietary caches are intentionally excluded.
